# Chrome + Firefox MV3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Same `notion-clipper-source/` loads unpacked in Firefox and Chrome and clips end-to-end.

**Architecture:** Unified MV3 manifest on a module service worker; DNR rule replaces the `webRequestBlocking` Origin strip; one guarded `browser`/`chrome` shim plus a single-call auth-flow wrapper.

**Tech Stack:** Vanilla JS, no deps, no build step; MV3 `declarativeNetRequest`; Node 18+ for `test.mjs`.

**Spec:** `docs/superpowers/specs/2026-09-21-chrome-mv3-design.md`

## Global Constraints

- No build step, no package.json, no dependencies.
- `cd notion-clipper-source && node test.mjs` must print `ok` after every task.
- Keep `auth.js` and `popup.js` free of top-level `document`/`browser` access (they import under plain Node in `test.mjs`).
- `vendor/` release builds never edited.
- Save-as mode resets to "new page" on every popup open — never sticky (untouched by this plan).

## Review Focus

- DNR rule silently not matching (e.g. typo in `urlFilter`) → clip fails with "Invalid Origin" instead of working; expect success with no Origin error on a real clip.
- User closes the Notion auth window → expect stored `auth_error` shown on next popup open, not a hang.
- Non-clippable tabs (`about:*`, `chrome://`, web-store pages) → expect the "Can't read this page" error, not a blank failure.
- Service worker suspends mid-sign-in → expect worst case "reopen popup to see result", never stranded tokens (rotation pair persisted before return).
- Pasted link of unknown kind (page vs database) → expect the one-retry path to still classify via Notion's error wording.

**Interfaces:**

- [ ] **Step 1: Add shim + wrapper to `auth.js`**

Insert after line 4 (`// moment focus moves...` comment block, before `const MCP = ...`):

```js
if (typeof globalThis.browser === "undefined" && typeof globalThis.chrome !== "undefined")
  globalThis.browser = globalThis.chrome;

// Single call: Firefox returns a promise (callback ignored), Chrome
// returns undefined and invokes the callback. Promise ignores the loser.
function webAuthFlow(url) {
  return new Promise((resolve, reject) => {
    const maybe = browser.identity.launchWebAuthFlow({ url, interactive: true }, (redirect) => {
      if (browser.runtime.lastError || !redirect)
        reject(new Error(browser.runtime.lastError?.message || "Sign-in closed."));
      else resolve(redirect);
    });
    maybe?.then?.(resolve, reject);
  });
}
```

Replace in `signIn`:

```js
  const redirect = await browser.identity.launchWebAuthFlow({ url, interactive: true });
```

with:

```js
  const redirect = await webAuthFlow(url);
```

- [ ] **Step 2: Rewrite `background.js` top**

Replace lines 1-12 of `notion-clipper-source/background.js`:

```js
import { signIn, signOut, accessToken } from "./auth.js";

// Notion's MCP server implements the spec's DNS-rebinding guard and rejects
// any browser origin ("Invalid Origin: <extension uuid>"). Desktop MCP clients
// send no Origin at all, so strip ours - scoped to this one host.
browser.webRequest.onBeforeSendHeaders.addListener(
  ({ requestHeaders }) => ({
    requestHeaders: requestHeaders.filter((h) => h.name.toLowerCase() !== "origin")
  }),
  { urls: ["https://mcp.notion.com/*"] },
  ["blocking", "requestHeaders"]
);
```

with:

```js
import { signIn, signOut, accessToken } from "./auth.js";

if (typeof globalThis.browser === "undefined" && typeof globalThis.chrome !== "undefined")
  globalThis.browser = globalThis.chrome;

// Origin strip lives in rules.json (DNR modifyHeaders) - webRequestBlocking
// is unavailable in Chrome MV3, so no listener here. Service workers are
// non-persistent: `pending` dedups within one lifetime only; the sign-in
// outcome persists via storage.local either way.
```

Keep the rest of the file (`pending`, `startSignIn`, `onMessage`) byte-identical.
